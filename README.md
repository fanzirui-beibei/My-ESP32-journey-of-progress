时钟项目

  在这个下午，我完成了一个基于ESP32-c3在oled上显示实时时间的项目。可能对于各位大佬来说很简单吧，但是对我来说其实挺难的，ardunio中下载库解决网络问题，甚至等到要插线了才发现原来需要母对母的杜邦线才能把oled和esp32连接起来，等等问题。
  这个项目的主要原理就是，先通过wifi的相关库函数，让开发板连接上wifi，然后通过wifi进入公网，访问ntp服务器要回当前时间，并将时间登记入变量，最后通过相关的函数转化成对应的字符串，显示AA:BB:CC,渲染到oled屏幕上。

                                                 一只会感知温度的小宠物

  这是我搭建的第二个项目，做成以后的感觉还是很好的，感觉oled屏幕上的这只猫活起来了，我宿舍热它就伤心，凉快了它就开心。

  最开始我还觉得不难，无非就是读取环境温度做个判断，输出对应心情的表情。但是我光光对这个显示的猫脸都折腾了很久，一开始想用取模软件从小红书上找图片直接复刻小白熊一二，想当然地要渲染到oled上，后来才发现我的小屏幕只有128x64，遂作罢。也想过把那个图片的分辨率调小，结果小了之后根本没法看，只能老老实实用u8g2来绘制图案拼接成猫脸。硬件和代码务必兼容呀。
  
  dht11方面倒没什么，都是esp32去主动呼叫它找它要数据而已。
  
  学到了状态机的概念，用了millis而不是delay。

  还有那该死的AI，告诉我esp32c3有触摸引脚，我也是太尽信它了觉得这么简单的东西应该不会胡说八道吧，结果后来一查规格书还真没有，我还是很想实现那种触摸反馈的功能呢。
  
  项目逻辑确实很简单，但只有真正动手做才能学到很多实际中的知识，遇到很多实际中需要克服的困难，我想要的就是遇到这些困难，解决它们也就提升了我的能力。
